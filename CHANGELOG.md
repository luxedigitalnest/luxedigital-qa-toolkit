# Changelog

All notable changes to LuxeDigital QA Toolkit are documented here.

## 1.1.0 — 2026-08-24

### Added
- PDF readability validation
- PDF page count and first-page dimensions
- PDF encryption warnings
- Safe SVG parsing
- SVG viewBox validation
- Embedded-raster warnings for SVG files
- Expanded automated test coverage
- GitHub Actions CI across Python 3.10, 3.11, and 3.12
- Distribution build and metadata checks
- PyPI trusted-publishing workflow
- PyPI-ready package metadata

## 1.0.0 — 2026-08-24

### Added
- Folder and ZIP scanning
- Empty and tiny file detection
- Filename checks
- Duplicate filename and content detection
- Raster image dimension checks
- 300-DPI print-size estimates
- File and package size warnings
- Markdown and JSON reports
- Command-line interface
